A bold landing-page theme for a web developer & digital creative, with services, a small-business offer, process, about, FAQ and a blog.

== Description ==

* Landing page with services pulled from WP Admin → Services (price, icon, tagline, booking link).
* "Book" buttons link to your booking app and pre-select the service.
* Business details, hero text, booking URL, price format and social links in Appearance → Customize → "Deea: Business details".
* Blog with cards, single posts with a booking call-to-action, comments and pagination.
* Structured data (ProfessionalService + services), self-hosted fonts, no external requests.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → choose deea.zip → Install → Activate.
2. Eight starter services are created on first activation. Edit them in WP Admin → Services.
3. Appearance → Customize → "Deea: Business details" → set your contact details and booking page URL.
4. Optional: Settings → Reading → "A static page" to use a separate Posts page for the blog.
